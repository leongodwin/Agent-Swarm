# FlowAgent environment inheritance

The adapter previously forwarded the entire office environment to its stdio child. It now supplies an explicit allowlist of runtime essentials, existing profile/cache locations, known Power Automate authentication/configuration settings, telemetry preferences and network/CA settings. The MCP SDK's own default environment inheritance is also restricted to its documented runtime/profile keys in the installed source.

Coding-provider credentials, unrelated GitHub/cloud secrets, Node preload/debug options, SSH agent sockets, office control variables and unknown configuration names are not implicitly forwarded. Windows names are normalized case-insensitively; POSIX names retain case-sensitive semantics. Function-style inherited values and undefined values are excluded. This is an environment boundary, not OS-account or filesystem isolation: the provider can still access files permitted to its process account.

Existing HOME/USERPROFILE, application-data, XDG, Azure configuration and FlowAgent cache directory references are preserved. No caches are copied, parsed or relocated, and no new authentication flow is introduced. Explicit known endpoint/cloud/proxy/CA settings retain their existing semantics; this allowlist does not certify those routes or replace approved identity/target/governance checks. Future plugin options need review before extending the allowlist.

Tests check retained configuration, rejected synthetic credentials/preload settings, Windows/POSIX casing and undefined/function values. An owned native child confirms the parent credential canary is absent. A second owned fixture uses the real MCP Client/StdioClientTransport handshake/discovery/call/close path to confirm the SDK does not reintroduce the canary or Node preload option, while explicit profile references arrive unchanged and closed-adapter calls are denied. That fixture implements local protocol replies only; it does not invoke real FlowAgent, Azure CLI, sign-in, token caches or tenant APIs.

Evidence: ignored `.swarm-reliability/flow-env-tests.txt`, `flow-env-native-tests.txt`, `flow-env-build-final.txt` and `flow-env-coverage.txt`. Initial focused checks passed (24 tests), and the native MCP fixture run passed separately. The full production goal remains active. Codex stays default; maintenance drain and Copilot Studio pause remain preserved.
